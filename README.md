# My HBCU Collective — Immersive 3D World Website

**The most advanced storyboard / world-scroll experience for the HBCU Collective.**

An immersive, continuous 3D universe you navigate by scrolling. Built with Three.js + modern web standards.

## Concept (from the original mind map)

Centered on **Myhbucollective.com** / HBCU Collective TV:

- HBCU by Association (Network · Radio · Podcast · Business Directory)
- On The Yard (news & culture pulse)
- Directory by Audience (Universities · Organizations · Alumni Associations)
- Venture Lab
- Coin/Token economy layer
- Social + Email
- “Free Google of the HBCU Space”

## Experience

Scroll drives a cinematic camera path through distinct 3D zones:

1. **Portal** — Enter the living network + search
2. **Network Galaxy** — Interconnected nodes of influence & media
3. **On The Yard** — Central cultural ground
4. **Directory Worlds** — Universities / Orgs / Alumni
5. **Venture Lab** — Innovation structure
6. **Token / Economy** — Shared value layer
7. **Join** — Call to enter the Collective

## Features

- Interactive 3D objects (hover for labels)
- Section navigation dots + top nav smooth scroll
- Search box for the free Google of the HBCU space
- Mouse parallax + cinematic CatmullRom camera path
- Responsive + mobile optimized

## Run locally

```bash
cd hbcu-collective
python3 -m http.server 8080
# open http://localhost:8080
```

Or any static server (Live Server, Vercel, Netlify, GitHub Pages, etc.).

## Files

- `index.html` — Structure + storyboard panels
- `styles.css` — Dark cinematic UI, gold/emerald palette
- `main.js` — Full Three.js world + scroll engine + interactions
